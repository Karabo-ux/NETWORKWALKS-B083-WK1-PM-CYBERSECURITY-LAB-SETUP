# NETWORKWALKS-B083-WK1-PM-CYBERSECURITY-LAB-SETUP

### Phase 1: Kali Linux Virtual Machine Setup


1. Downloaded and installed 7-Zip** to extract compressed virtual machine files.
2. Downloaded and installed Oracle VirtualBox** to create and manage virtual machines.
3. Configured the VirtualBox network settings** by creating a NAT Network using the `10.0.0.0/24` subnet.
4. Downloaded and imported the Kali Linux virtual machine** into VirtualBox.
5. Configured the Kali Linux IP settings** to establish network connectivity within the virtual environment.
6. Created a virtual machine snapshot** to preserve the configured state and provide a recovery point for future practical exercises.
